# Раздел «Помощь и ЧаВо»

Профиль → «Помощь и ЧаВо»: быстрый старт, руководство по экранам с картинками и частые вопросы.

- Тексты: `src/i18n/help.ru.ts` (основной) и `src/i18n/help.en.ts`. id разделов и число вопросов
  совпадают во всех языках — это проверяет `src/help/help.test.ts`. `**так**` — жирный текст.
- Экран: `src/screens/Help.tsx` (разделы и вопросы раскрываются по нажатию).
- Картинки: `assets/help/<язык>/<id раздела>.png` — скриншоты демо-режима, светлая тема, ширина 390 px.

## Переснять картинки после изменения экранов

```bash
EXPO_OFFLINE=1 npm run build:web       # сборка в dist/ (с версией и датой выпуска)
npm run help:shots                      # нужен playwright; пишет PNG и src/help/shots.gen.ts
```

Новый раздел: добавить его в оба словаря и строку `shot('<id>', …)` в `scripts/help-shots.cjs`.
Новый язык: добавить его в `LANGS` в том же скрипте и переснять.
