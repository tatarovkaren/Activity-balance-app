# Обратная связь (Профиль → «Обратная связь»)

Тестер выбирает «Ошибка / Идея / Вопрос» и нажимает кнопку. Приложение собирает заготовку:
версия и сборка, устройство и браузер, размер экрана, установлено ли на экран, язык, режим (демо / на устройстве / с аккаунтом), дата.
Личных данных в ней нет (ни цифр, ни имени, ни почты).

- **В браузере:** заготовка копируется, и открывается Telegram-чат для отзывов. Тестер вставляет текст, дописывает подробности, прикладывает скриншот.
- **В мобильном приложении:** открывается системное «Поделиться» (выбрать Telegram и чат).
- **Пока чат не задан:** кнопка «Скопировать заготовку», подсказка отправить её тому, кто прислал приложение.

## Где задать чат

Одна настройка, любой из двух способов:

1. `FEEDBACK_CHAT` в `src/feedback/index.ts` — ссылка-приглашение группы `https://t.me/+…` (или `@имя` публичной группы).
2. Переменная окружения `EXPO_PUBLIC_FEEDBACK_CHAT` при сборке (на Vercel: Settings → Environment Variables, затем Redeploy). Переменная важнее значения в коде.

Ссылки не на t.me / telegram.me / tg:// игнорируются.

Telegram не умеет вставлять текст в поле ввода по ссылке-приглашению группы, поэтому заготовка идёт через буфер обмена.
