# Информационный Telegram-канал: очередь постов

Посты канала лежат в репозитории как файлы, а GitHub раз в день (около 9:00 МСК) отправляет в канал
один созревший пост через бота. Пост попадает в очередь только через PR: **слить PR = одобрить посты**.
Концепция канала, рубрики и контент-план — `plan/telegram-kanal-2026-11-21.pdf` в файлах проекта.

- Посты: `channel/posts/<дата>-<название>.md`. Отправленные отмечаются в `channel/published.json`
  (workflow сам коммитит этот файл в `main`; руками его не трогать).
- Workflow: `.github/workflows/channel-post.yml`; логика — `src/channel/posts.ts`; отправка — `scripts/channel-post.mjs`.
- Тест `src/channel/posts.test.ts` проверяет каждый пост: разметку, длину, хештег рубрики, строку «Источник».
- Посмотреть очередь у себя: `node --experimental-strip-types scripts/channel-post.mjs` (без `--send` ничего не отправляет).

## Формат поста

```
---
publish_at: 2026-11-25T09:00+03:00
---
🔬 <b>Заголовок</b>

Текст… <a href="https://doi.org/…">doi</a>

Источник: …
#наука
```

- Разметка Telegram HTML: `<b>`, `<i>`, `<u>`, `<s>`, `<a href="https://…">`, `<code>`, `<blockquote>`. Символы `<`, `>`, `&` в тексте — как `&lt;`, `&gt;`, `&amp;`.
- До 4 096 символов. Предпросмотр ссылок выключен.
- Обязателен хештег рубрики: `#наука`, `#мифилифакт`, `#каксчитать`, `#приложение`; в первых трёх — строка «Источник:»/«Источники:».
- Правила содержания — как у Wiki (`docs/wiki.md`): ссылки сверены с PubMed, гипотезы не выдаём за факт, пишем ограничения, без медицинских обещаний.

## Как работает расписание

- Запуск каждый день в 06:00 UTC (9:00 МСК; GitHub иногда запускает с задержкой до ~30 минут).
- Отправляется **один** самый ранний пост, у которого наступило `publish_at` (с запасом в час) и которого нет в `published.json`.
  Два поста на один день — второй уйдёт на следующий день.
- Пост, просроченный больше чем на 3 дня, **не отправляется** (предупреждение в журнале Actions) — поставьте ему новую дату через PR.
  Это страховка: если канал или секреты появятся позже, старые посты не посыплются залпом.
- Если пост отправлен, а отметку сохранить не удалось (запуск красный) — допишите его id в `channel/published.json`, иначе он уйдёт повторно.

## Как включить (один раз)

1. **Канал** создан (публичный или частный).
2. **Бот — администратор канала.** Используем бота сообщений тестерам (токен уже в секрете `TESTERS_BOT_TOKEN`, см. `docs/release-notify.md`).
   Канал → название → Изменить → Администраторы → Добавить администратора → найти бота по адресу.
   Права: только «Публикация сообщений», «Изменение сообщений», «Удаление сообщений».
3. **Секрет `CHANNEL_CHAT_ID`** (Settings → Secrets and variables → Actions → New repository secret):
   - публичный канал — его адрес, например `@activitybalance`;
   - частный — номер вида `-100…`: опубликуйте в канале любое сообщение, откройте
     `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите `"channel_post":{… "chat":{"id":-100…`.
4. **Проверка.** Actions → «Пост в Telegram-канал» → Run workflow: без галочки — покажет очередь и что ушло бы сейчас;
   с галочкой — отправит созревший пост.

Отключить: удалить секрет `CHANNEL_CHAT_ID` или выключить workflow в Actions.
