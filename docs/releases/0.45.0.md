# Activity Balance 0.45.0 — Chill mode (2026-11-26)

## Scope
- New `Chill` display mode alongside Basic and Advanced, retaining Basic as default and the shared diary/calculation engine.
- Four quick-entry actions in a 2×2 grid: weight, nutrition, activity and wellbeing; body measurements available in a separate full-width card.
- Modal dialogs use the same underlying diary data and save only after confirmation.
- Four compact 14-day progress charts in a 2×2 grid: weight, calories, steps and wellbeing; figures are derived only from actual recorded entries.
- Access to FatSecret import, food catalogue, food photo entry and full graphs from Chill.
- The calorie-versus-macros discrepancy warning remains available in Chill.
- UI localized in Russian and English.
- Removed the manual 1/2-column selector after Fold testing; localized 2×2 Chill cards are *not* a global Fold layout mode.
- Generator for the Telegram notify function and generated source synchronized; Russian nonbreaking-space test corrected.

## Validation
- Visual smoke test on an unfolded Xiaomi Fold, confirmed by project owner.
- TypeScript + all Vitest tests passed on PR checks prior to merge.
- Re-test production deployment and core entry flows after merge.
- GitHub Issue #58: user experience. Issue #60: CI regression.
- #51 curator permissions and other backend issues are not resolved by this release.

## Release handling
- Keep old versions. Use a privacy-filtered GitHub Actions artifact to deliver a complete snapshot of tracked repository sources, code, docs and tests to the project's Google Drive code folder.
- The privacy-filtered archive does not contain `.env` or personal hand-calibration notes; see its manifest for exclusions.
