# Заявка «Хочу куратора» (Профиль → «Куратор»)

Если у клиента нет куратора, под полем кода есть блок «Нет куратора?» и кнопка «Хочу куратора».
Форма: цель (снизить / набрать / держать вес / другое), имя, как связаться (Telegram / почта / телефон),
коротко о себе (до 1000 знаков), галочка «приложить цифры из профиля» (пол, возраст, рост, последний вес, целевой вес)
и обязательная галочка согласия на передачу контакта.

Подбора куратора в приложении пока нет: заявку получает команда письмом и отвечает клиенту сама.
В приложении запоминается только дата последней заявки (`AppData.curatorRequest`).

## Как заявка доходит до почты

Без своего сервера, через бесплатный сервис форм **Web3Forms** (`src/curator-request`):
приложение отправляет JSON на `https://api.web3forms.com/submit`, сервис пересылает письмо
на почту, к которой привязан ключ. Почта в коде не видна. Бесплатно — 250 заявок в месяц.
Если клиент выбрал «почта», его адрес ставится в «Ответить» (replyto).

### Включить отправку

1. web3forms.com → «Create your Access Key» → ввести почту для заявок → ключ придёт письмом.
2. Ключ (UUID) — в `CURATOR_FORM_KEY` в `src/curator-request/index.ts`
   или переменной `EXPO_PUBLIC_CURATOR_FORM_KEY` при сборке (Vercel → Settings → Environment Variables → Redeploy).
   Ключ не секретный: по нему можно только отправить письмо на эту почту.

Пока ключа нет — демо: заявка собирается, на экране показывается письмо, которое получила бы команда, никуда не уходит.

Ограничения: бесплатный тариф Web3Forms рассчитан на отправку из браузера (веб-версия/PWA).
Для мобильных приложений и для журнала заявок — следующий шаг ниже.

## Следующий шаг (после подключения Supabase)

Таблица `curator_requests` (журнал с статусом «новая / в работе / передана куратору») + Edge Function,
которая на новую заявку шлёт сообщение в Telegram команде (через бота уведомлений, токен только в секретах Supabase)
и письмо. Токен бота в приложение класть нельзя: любой сможет писать от имени бота.
