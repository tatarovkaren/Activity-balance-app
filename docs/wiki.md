# Wiki: баланс энергии

Профиль → «Wiki: баланс энергии» — научно-популярный раздел: ключевые исследования о похудении и наборе массы, у каждого — краткая суть, ограничения, связь с расчётами приложения и ссылки (DOI, PubMed).

- Библиография (не зависит от языка): `src/wiki/refs.ts` — авторы, год, журнал, том(выпуск):страницы, DOI, PMID, тип работы; порядок по разделам — `WIKI_SECTIONS`.
- Тексты: `src/i18n/wiki.ru.ts` (основной) и `src/i18n/wiki.en.ts`, ключи `items` — id из `refs.ts`. `**так**` — жирный текст.
- Экран: `src/screens/Wiki.tsx`. Тест `src/wiki/wiki.test.ts` проверяет формат DOI/PMID, что каждый источник в одном разделе и что тексты есть на всех языках.

## Правила для новых источников

1. Сверить с PubMed или сайтом журнала: авторы, год, журнал, том, страницы, DOI, PMID.
2. Суть писать по аннотации и тексту работы: размер выборки, длительность, тип (РКИ, обзор, метаанализ, модель, наблюдение). Не выдавать гипотезы авторов за установленный факт.
3. В «Ограничения» — то, что мешает переносить вывод на обычного пользователя.
4. Добавить запись в `WIKI_REFS`, id — в нужный раздел `WIKI_SECTIONS`, тексты — в оба словаря.
