# Версии и дата выпуска

Раздел «О приложении» (Профиль) и низ «Помощи» показывают версию и дату выпуска. Вручную их нигде не пишут.

## Откуда берутся

| Что | Источник |
| --- | --- |
| Номер версии | поле `version` в `package.json` (единственное место, где он задаётся) |
| Дата выпуска | дата последнего коммита, из которого собрано приложение, по Москве |
| Сборка | короткий хэш этого коммита (на Vercel — `VERCEL_GIT_COMMIT_SHA`) |

`scripts/build-version.mjs` пишет их в `src/about/version.gen.ts` (файл не в git) и переносит номер в `app.json` (`expo.version`), чтобы мобильные сборки показывали тот же номер. Скрипт запускается сам после `npm install` / `npm ci`, перед `npm run build:web` и `npm run web`; вручную — `npm run version:gen`. На Vercel команда сборки — `npm run build:web`.

## Схема номера: MAJOR.MINOR.PATCH

- **0.x.y — до публичного запуска** (демо, пилот с кураторами). `1.0.0` — первый публичный выпуск.
- **MINOR (+1, PATCH = 0)** — выпуск с новой функцией или заметным изменением экрана. На практике: каждый PR с новой функцией поднимает MINOR в `package.json`.
- **PATCH (+1)** — только исправления и мелкие правки текста.
- **MAJOR** — 1.0 при запуске; дальше — крупная смена продукта или формата данных, несовместимая с прежними резервными копиями.

Отсчёт: до этого номер не менялся (стоял `1.0.0`). С PR «О приложении» — `0.27.0`: 26 слитых PR до него, этот — 27-й выпуск.
