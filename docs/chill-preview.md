# Chill / Basic / Advanced — Preview для тестирования (Issue #58)

## Что сделано
- Добавлен третий режим профиля `chill`, значение по умолчанию `basic` сохранено.
- Экран «День» в режиме Chill показывает дату и 4 крупные кнопки: Вес, Питание, Активность, Самочувствие.
- Каждая кнопка открывает краткую форму ввода. «Сохранить» записывает только поля выбранной категории в **тот же** дневник `day_entries` / локальное состояние; «Отмена» ничего не сохраняет.
- Способы добавления еды через справочник и фото доступны. В нижней навигации Chill остаются «День» и «Профиль», где можно вернуться к Basic/Advanced.
- Все сохранённые ранее записи и формулы не мигрируются; добавлены RU/EN подписи.
- `useAdvanced()` теперь явно включается только в advanced — в Chill не показываются экспертные метрики на вспомогательных экранах.

## Инструкция для теста на Xiaomi Fold
1. Открыть Preview URL ветки (не production), войти в привычный аккаунт.
2. Профиль → Режим приложения → «Чиловый»; вернуться в «День».
3. Проверить отображение четырёх кнопок на внешнем экране и при раскрытии телефона, а также прокрутку, клавиатуру и диалоги.
4. Для каждого поля проверить ввод, «Отмена» (не сохраняет), «Сохранить» (сохраняет).
5. Вернуться в «Базовый»/«Продвинутый» и проверить те же сохранённые числа.
6. Проверить переключение режима при раскрытии/закрытии Fold, а также обновление страницы и повторную авторизацию.
7. Прислать скриншоты и описания проблем, указать язык и внешний/внутренний экран.

**Важно:** Preview может быть подключён к рабочему Supabase окружению. Для первой проверки использовать тестовый аккаунт и тестовые даты/значения, если не подтверждено выделенное тестовое окружение. Preview не разворачивает отдельную базу сам по себе.

## Повторные замечания с Xiaomi Fold — 26.11.2026, 16:51
В Preview пользователь проверил выбор колонок на внутреннем экране и графики. Решение: **Chill оставить; удалить настройку количества колонок (оказалась неудобной); добавить замеры тела непосредственно в Chill/День.**

### Изменения этой итерации
- Из профиля удалена карточка «Компоновка экрана». Старые сохранённые значения `layoutMode` не удаляются и игнорируются ради совместимости с облаком и архивами. На внешнем и внутреннем экранах используется одна читаемая колонка с ограничением ширины; двухколоночные модификации экранов Day, Fact и Charts откатили.
- Добавлена **пятая кнопка «Замеры тела»** в Chill/День. В отдельной модальной форме доступны окружности **шеи, талии, бёдер, груди и бицепса** (в сантиметрах). Бёдра важны для женской формулы; мужчине поле также доступно как необязательное. Данные записываются штатно через `setDay(sel, patch)` и доступны во всех режимах и на графиках.
- Правило: визуализация **изменения** объёма тела требует минимум **двух измерений одного и того же параметра в разные даты**; дополнительная подсказка дана в диалоге.
- Для всех параметров возможно частичное заполнение, работа с прошлыми датами через уже существующие кнопки навигации даты; кнопка «Отмена» ничего не записывает.

### Проверить на устройстве
1. Профиль: есть выбор Chill/Basic/Advanced, **нет переключателя 1/2 колонки**.
2. В Chill/День: пункт «Замеры тела» открывает форму; сохрани талию и шею на первой дате.
3. Перейди на другую дату, введи новые значения тех же полей; убедись, что вкладка «Графики» показывает изменение объёмов.
4. Переключись на Базовый/Продвинутый и убедись, что оба замера видны в общем дневнике.
5. Сверь внешний/раскрытый экран и сохранение при открытии клавиатуры.

## Утверждённая сетка Chill — 26.11.2026, итоговое решение
Владелец согласовал последнюю иллюстрацию для режима Chill. В PR #59 реализованы:
- четыре основные кнопки **Вес / Питание / Активность / Самочувствие** — компактные карточки в **две колонки**;
- **Замеры тела** — отдельная карточка на полную ширину, существующий диалог сохранён;
- «Твой прогресс»: компактные графики **веса, калорий, шагов, самочувствия** в сетке **2×2** на 14-дневном периоде;
- сводные значения только из фактически сохранённых записей: динамика веса — лишь при минимум двух взвешиваниях, последние зарегистрированные калории, средние шаги и самочувствие по дням с данными; при недостатке данных показывается текст, не вымышленные графики;
- сохранены FatSecret CSV/PDF, справочник, фото, предупреждение о несовпадении калорий и БЖУ, переход к полной аналитике.

Это **локальная сетка карточек Chill**, а не возвращение снятого пользователем переключателя 1/2 колонок. Остальные режимы остаются с прежней компоновкой. Внешний и внутренний экраны Fold требуют повторной проверки ширин/переноса подписи, отображения диаграмм и модальных окон.

На момент записи обновлён только Draft PR #59, Production и версия не менялись. До merge требуется успешный typecheck/тесты, физический осмотр на Fold, проверка предупреждений и одобрение владельца. Ошибки базового набора тестов зафиксированы в Issue #60.
