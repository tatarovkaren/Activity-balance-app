# Языки интерфейса

Интерфейс есть на русском и английском. Язык выбирается в профиле (карточка «Язык») и на экране входа: «Как в системе», «Русский», «English». Выбор хранится в профиле вместе с темой (`profile.lang`) и синхронизируется с облаком.

«Как в системе» берёт первый поддержанный язык браузера или телефона. Если язык системы не поддержан, для стран СНГ (be, kk, ky, uz, tg, tk, hy, az) включается русский, для остальных — английский.

## Как устроено

- `src/i18n/ru.ts` — основной словарь. Его структура задаёт тип `Dict`.
- `src/i18n/en.ts` — английский словарь с типом `Dict`: если ключа не хватает, не соберётся `npm run typecheck`, а тест `src/i18n/i18n.test.ts` проверит, что ключи совпадают и в английском нет кириллицы.
- `src/i18n/format.ts` — числа и даты по правилам языка из раздела `fmt` словаря: десятичный знак (72,5 / 72.5), разделитель тысяч (12 000 / 12,000), даты (16.11.2026 / Nov 16, 2026), дни недели, формат даты в полях ввода (ДД.ММ.ГГГГ / YYYY-MM-DD). Intl не используется, чтобы формат был одинаковым на вебе и Android. Даты разбираются только по местному времени, без `toISOString`.
- `src/i18n/core.ts` — список языков (`LANGS`), выбор языка, перевод кодов ошибок, названия продуктов; `src/i18n/index.tsx` — провайдер и хук `useI18n()` → `{ lang, tx, f }`.
- Ядро расчётов (`src/core`) текстов не возвращает: причины исключения дней, автонаходки, ошибки импорта и облака, подсказки фото-сервиса — коды и числа, а текст подставляет интерфейс.
- Тексты отчёта куратору (картинка) и подписи графиков, включая выгрузку PNG/PDF, — на языке того, кто их делает.
- Единицы пока метрические в обоих языках (кг, см, ккал). Фунты и дюймы — отдельная задача.

## Как добавить язык (например, казахский)

1. Добавить код в `Lang` в `src/core/types.ts`: `export type Lang = 'ru' | 'en' | 'kk';`.
2. Скопировать `src/i18n/en.ts` в `src/i18n/kk.ts`, перевести строки и раздел `fmt` (месяцы, дни недели, разделители, порядок даты).
3. Добавить строку в `LANGS` в `src/i18n/core.ts`: `kk: { name: 'Қазақша', dict: kk }` (название — на самом языке).
4. Если язык больше не нужен в запасном списке СНГ (`FALLBACK_RU`), убрать его оттуда.
5. `npm run typecheck && npm test` — подскажут пропущенные ключи и непереведённые продукты.

Плюральные формы задаются функциями в словаре (`days: (n) => …`), поэтому язык с любыми правилами множественного числа описывается без изменений в коде экранов.
