# Сообщение тестерам о новой версии (Telegram)

Когда в `main` вливается PR, который поднимает `version` в `package.json`, GitHub сам отправляет
в группу отзывов тестеров короткое сообщение: номер версии, пункты «Что нового» (верхняя запись
`src/about/changelog.ts`, по-русски) и ссылку на сайт.

- Workflow: `.github/workflows/release-notify.yml`; текст — `src/about/releaseMessage.ts`; отправка — `scripts/release-notify.mjs`.
- Если версия не менялась — ничего не шлётся. Если секреты не заданы — тоже ничего (только предупреждение в Actions).
- Если номер в `package.json` и верхняя запись changelog не совпадают — сообщение не уходит, запуск красный.
- Посмотреть текст у себя: `node --experimental-strip-types scripts/release-notify.mjs` (без `--send` ничего не отправляет).

## Как включить (один раз)

1. **Бот.** В Telegram откройте @BotFather → `/newbot` → имя (например, «Activity Balance — новости»)
   и адрес, оканчивающийся на `bot`. BotFather пришлёт токен вида `123456:ABC…`. Токен никому не пересылайте.
   Отдельный бот лучше, чем основной @activity_balance_bot: тот отвечает на сообщения (вес числом и т. п.)
   и в группе начал бы реагировать на сообщения тестеров.
2. **Добавьте бота в группу** отзывов как участника (в группе: участники → добавить → найти бота по адресу).
   Если в группе ограничены права участников — разрешите боту отправлять сообщения (или сделайте админом).
3. **Узнайте номер группы (chat_id).** В группе отправьте `/start@адрес_бота`. Затем в браузере откройте
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates` (вместо `<ТОКЕН>` — токен бота). На странице найдите
   `"chat":{"id":-100…` — это число вместе с минусом и есть номер группы. Если страница пустая (`"result":[]`) —
   отправьте `/start@адрес_бота` в группу ещё раз и обновите страницу.
4. **Секреты в GitHub.** Репозиторий → Settings → Secrets and variables → Actions → New repository secret:
   - `TESTERS_BOT_TOKEN` — токен бота;
   - `TESTERS_CHAT_ID` — номер группы (с минусом).
5. **Проверка.** Actions → «Сообщить тестерам о новой версии» → Run workflow:
   - без галочки — только покажет текст в журнале запуска, в группу ничего не уйдёт;
   - с галочкой «Отправить в группу» — отправит сообщение о текущей версии;
   - в поле «Сколько последних версий» можно указать, например, 6 — придёт одно сообщение с изменениями шести последних версий.

Отключить: удалить секрет `TESTERS_BOT_TOKEN` (или выключить workflow в Actions).
