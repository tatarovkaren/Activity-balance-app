# Уведомления: пуш в браузере и Telegram-бот

Что приходит пользователю (каждое выключается в Профиле → «Уведомления»):

| Напоминание | Когда | Условие |
|---|---|---|
| Взвеситься утром | в выбранное время, по умолчанию 08:00 | вес за сегодня не вписан |
| Дневник не заполнен | в выбранное время, по умолчанию 21:00 | за день нет калорий и приёмов по фото, день не отмечен как необычный |
| Комментарий куратора | через 0–5 минут после комментария | — |
| Резервная копия | в 12:00, не чаще раза в неделю | копии не было 7 дней |

Время местное, по часовому поясу устройства (приложение сохраняет его в профиль). Если сервер пропустил
время (спал), напоминание догоняет в течение 3 часов, а позже не приходит, чтобы не будить ночью.
В сообщениях нет цифр дневника и текста комментариев: только повод открыть приложение.

Каналы:

- **Пуш в браузере (PWA).** Android и компьютер — сразу. iPhone и iPad — только в приложении, добавленном на
  экран «Домой», iOS 16.4 и новее. Включается на каждом устройстве отдельно.
- **Telegram-бот.** Работает на любом телефоне. Привязка: Профиль → «Подключить» → в боте «Старт».
  Отвязка: там же или командой `/stop` в боте.
- В мобильном приложении (этап 4) — Expo Push, для Android без сервисов Google — RuStore.

## Как это устроено

- Настройки — в профиле (`profiles.data.notify`), тип `NotifyPrefs` в `src/core/notify.ts`.
- Таблицы — миграция `supabase/migrations/0007_notifications.sql`: подписки браузеров, привязки Telegram,
  журнал отправленного (одно напоминание не уходит дважды), секреты сервера.
- Отправляет функция `supabase/functions/notify` (логика и тексты — `logic.ts`, шифрование пуша — `webpush.ts`,
  тесты — `src/core/notify.test.ts`). Каждые 5 минут её вызывает `pg_cron`.
- Ключи для пушей (VAPID) функция создаёт сама при первом запуске и хранит в базе.
  Расписание и вебхук Telegram она тоже ставит сама. Вручную — только токен бота.

## Подключить (один раз, около 15 минут)

Нужен уже подключённый сервер Supabase ([supabase-setup.md](supabase-setup.md)).

### 1. Таблицы

Если `supabase/setup.sql` запускали **после** 19.11.2026, таблицы уже есть — шаг пропустить.
Иначе: Supabase → **SQL Editor** → **New query** → вставить весь файл
[`supabase/migrations/0007_notifications.sql`](../supabase/migrations/0007_notifications.sql) → **Run**.

Проверить расширения: **Database** → **Extensions** → `pg_cron` и `pg_net` включены (если нет — включить).

### 2. Telegram-бот (если нужен)

1. В Telegram найти **@BotFather** (с синей галочкой) → **Start**.
2. Отправить `/newbot`.
3. Имя бота, например `Activity Balance`.
4. Адрес бота латиницей, обязательно на `bot`, например `activity_balance_bot` (если занят — придумать другой).
5. BotFather пришлёт **токен** вида `1234567890:AA...`. Это пароль бота: **никому не присылать, в чат тоже**.
6. По желанию: `/setuserpic` — картинка бота, `/setdescription` — текст «Напоминания Activity Balance:
   взвеситься, заполнить дневник, комментарий куратора».

Токен: Supabase → **Edge Functions** → **Secrets** → **Add new secret**:
имя `TELEGRAM_BOT_TOKEN`, значение — токен → **Save**.

### 3. Функция `notify`

Вариант без программ: Supabase → **Edge Functions** → **Deploy a new function** → **Via Editor**:

1. Имя функции: `notify`.
2. Стереть пример и вставить **весь** файл [`supabase/dashboard/notify.ts`](../supabase/dashboard/notify.ts)
   (на GitHub: кнопка **Raw** → выделить всё → скопировать).
3. **Deploy function**.
4. Открыть функцию → **Details** (или **Settings**) → выключить **Enforce JWT Verification** (Verify JWT) → **Save**.
   Вход пользователя функция проверяет сама, а Telegram и расписание приходят без входа.

Вариант с Supabase CLI: `supabase functions deploy notify --no-verify-jwt`.

После изменений в коде функции файл для редактора пересобирается командой `npm run fn:bundle`.

### 4. Проверка

1. Открыть сайт, войти в аккаунт → Профиль → «Уведомления». Кнопки «Включить» и «Подключить» стали активными.
2. «Подключить» → в Telegram «Старт» → бот ответит «Готово!» → в приложении «Проверить».
3. Пуш: «Включить» → разрешить уведомления.
4. «Прислать тестовое» — сообщение придёт в Telegram и пушем.
5. Через 5–10 минут в Supabase → **Integrations** → **Cron** (или SQL `select * from cron.job;`)
   появится задание `activity-balance-notify`.

## Если что-то не так

- **Кнопки неактивны, «Сервер уведомлений ещё не подключён»** — функция `notify` не развёрнута или называется иначе.
- **«Telegram-бот на сервере ещё не подключён»** — нет секрета `TELEGRAM_BOT_TOKEN` или в нём опечатка.
  После исправления секрета нажать **Deploy** у функции ещё раз.
- **Тестовое приходит, а напоминания нет** — нет задания в Cron: проверить, что `pg_cron` и `pg_net` включены,
  затем открыть в приложении Профиль (функция при вызове сама ставит расписание).
- **Логи** — Edge Functions → `notify` → **Logs**.
